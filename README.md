# clone-probe

一个用来观察 GitHub Traffic 的对照实验仓库。

## 目的

对比「公开仓库」和「私有仓库」的 clone 计数，验证一个猜测：

> 新建的公开仓库会在发布当天被扫描服务批量 clone，而私有仓库不会。

对照组：`Asukahimi/krea2-pose-tool`、`flver-to-ue` 等 —— 2026-10-21 建仓后当天出现 17~20 次 clone / 11~13 个独立来源。

## 记录

| 时间（Asia/Shanghai） | 动作 | clone 计数 |
|---|---|---|
| 2026-10-22 19:25 | 建仓（private）+ 首次推送 | 待观察 |

## 预期

私有仓库不进入公开事件流，外部服务无法 clone，因此计数应长期为 0。
如果这里也是 0，说明公开仓库那批 clone 确实来自「公开可见」这个条件本身。
